# Pizza Wala

Welcome to Pizza Wala 🚀🍕

This is the official source code for the Pizza Wala app.

## About

Pizza Wala ek modern pizza ordering app hai jahan users apna favourite pizza order kar sakte hain aur apni choice ke hisaab se custom pizza bana sakte hain.

## Features

- 🍕 Pizza Menu
- 🛒 Cart System
- 🧀 Create Your Own Pizza
- 📦 Order Management
- ⭐ Customer Reviews

## Unique Feature

User apna pizza khud design kar sakta hai:
- Pizza Base select kare
- Cheese choose kare
- Toppings add kare
- Sauce select kare

App automatically final price calculate karega.
