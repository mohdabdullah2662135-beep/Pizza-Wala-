# PizzaWala App Plan 🍕

## App Goal
PizzaWala ek pizza ordering app hai jahan customer easily pizza choose aur order kar sakta hai.

## User Screens

1. Home Screen
- Pizza categories
- Offers
- Popular pizzas

2. Menu Screen
- Pizza list
- Price
- Add to cart button

3. Custom Pizza Screen
- Choose base
- Choose cheese
- Choose toppings
- Choose sauce

4. Cart Screen
- Selected items
- Total price
- Checkout

5. Order Screen
- Order status
- Delivery updates

## Future Features
- AI pizza suggestion
- Loyalty points
- Online payment
